| 3 | `3_Simulation` | **The "Vision"** — UI mockups, image carousel |

| 6 | `6_Semblance` | **The "Scars"** — Error logs, workarounds, gap analysis |
| 7 | `7_Testing_Known` | **The "Proof"** — Validation, checklists, outcome confirmation |
