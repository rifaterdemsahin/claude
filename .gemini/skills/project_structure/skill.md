This skill defines the 7-stage project structure logic. Use this skill when asked where to place a new file, or when navigating the project.

# Project Structure Logic (7-Stage Journey)
- `1_Real_Unknown/`: The "Why" — Problem definitions, OKRs, core questions.
- `2_Environment/`: The "Context" — Roadmaps, constraints, setup guides.
- `3_Simulation/`: The "Vision" — UI mockups, image carousel.
- `4_Formula/`: The "Recipe" — Step-by-step guides, research notes, build logic.
- `5_Symbols/`: The "Reality" — Source code, implementation.
- `6_Semblance/`: The "Scars" — Error logs, near-misses, workarounds.
- `7_Testing_Known/`: The "Proof" — Validation, testing checklists, outcomes.

**Rules**:
- Obsolete files go into a `_obsolete/` sub-folder within their respective directory.
- All files must be placed strictly in one of these numbered folders unless they are root configuration files.
