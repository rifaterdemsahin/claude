This skill defines the markdown and formatting standards for this project. Use this skill when generating or modifying any `.md` or `.html` documentation.

# Markdown Standards
- **Headings**: Use hierarchical headings (`#`, `##`, `###`).
- **Syntax Highlighting**: Use PrismJS compatible language tags in fenced code blocks.
- **Diagrams**: Use `mermaid` syntax for architecture and logic flow diagrams.
- **Emojis**: Use emojis (✨, 🛠, 🧪, 🐛) to make content more scannable.
- **Links**: Ensure external links use the `[Text](URL)` format and open in a new tab when applicable.
